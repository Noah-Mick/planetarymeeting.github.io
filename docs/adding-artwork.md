# Adding artwork to the website

Everything on planetarymeeting.com comes from one Dropbox folder. Put a piece
in, it appears on the site. Take it out, it comes off. You never need to touch
the website itself.

---

## Adding a piece

1. In Dropbox, open **Apps → Planetary Meeting**.
   *(Worth starring this folder so it sits at the top of your sidebar.)*
2. Open the folder for the gallery you want: **Illustration**, **Sketchbook**,
   or **Fine Art**.
3. Drop your PNG or JPEG in.
4. Name the file whatever you want the piece to be called.

That's it. The site updates itself within about fifteen minutes.

**The filename becomes the title on the website.** `Snow Dogs.png` shows up as
*Snow Dogs*. So spell it the way you want people to read it — capital letters,
apostrophes and spaces are all fine.

---

## Choosing the order

Put a number and a dash at the front of the filename:

```
01 - A Day Spent Outside.png
02 - Snow Dogs.png
03 - In a Forest.png
```

Those appear first, in that order. The format is **number, space, dash, space**.

Anything without a number goes underneath, oldest first. So if you forget a
number nothing breaks — the piece just lands at the bottom, and you can add a
number later whenever you feel like it.

A few things that are fine and won't break anything:

- **Skipping numbers.** `01`, `02`, `07` just appear one after another. No gaps
  on the site.
- **Two files with the same number.** They'll sit next to each other, the older
  one first.
- **Renumbering later.** Rename as much as you like — it costs nothing and
  happens quickly, because renaming doesn't re-upload the picture.

To move a piece to the top, give it `01` and bump the others down.

---

## Sketchbook pages without a title

Photos straight off your phone — `Photo Nov 28 2023, 6 55 59 PM.jpg` — go up
with **no title shown**, which is what you want for a page that isn't really
called anything.

If you later decide it deserves a name, just rename the file and the title
appears.

---

## Renaming, reordering, removing

| To do this | Do this in Dropbox |
|---|---|
| Rename a piece | Rename the file |
| Change the order | Change the number at the front |
| Move to another gallery | Drag it to the other folder |
| Replace with a better scan | Drop the new file in, same name, overwrite |
| Take it off the site | Delete the file (or move it out of the folder) |

**The website is a mirror of the Dropbox folder.** Whatever is in there is
what's on the site. That's the whole rule.

---

## Things worth knowing

**Give it fifteen minutes.** The site checks Dropbox every quarter hour. If
you've just added something and don't see it yet, wait a bit and refresh. It's
also worth making sure Dropbox has finished syncing on your end — a file still
uploading hasn't arrived yet.

**PNG and JPEG only.** Anything else is ignored. HEIC photos from an iPhone
need converting first.

**Upload the good version.** The website automatically makes its own smaller
copies for the web, so you don't need to shrink or export anything — send the
full-quality file straight in and let it do the work.

**Your Dropbox is the only copy of the full-resolution file.** The website
keeps a high-quality web version, not your master. So keep these folders backed
up the way you'd keep any other originals.

**Nothing can edit your Dropbox.** The website only ever reads from it. It can
never rename, move or delete your files.

**Deleting a lot at once is blocked on purpose.** Removing more than three
pieces in one go pauses and asks for confirmation, so an accidental drag can't
empty a gallery. If you genuinely meant it, ask Noah to confirm the run. (This
also means a Dropbox sync going wrong can't wipe the website.)

---

## If something doesn't show up

Work down this list:

1. Has Dropbox finished syncing? Check for the green tick.
2. Has it been more than fifteen minutes?
3. Is the file a PNG or JPEG?
4. Is it in one of the three gallery folders, and not loose in the parent
   folder or a sub-folder?
5. Try a hard refresh — **Ctrl+Shift+R**, or **Cmd+Shift+R** on a Mac.

If it's still missing, tell Noah — there's a log showing exactly what the site
saw and what it skipped, so it's usually quick to spot.
